
An AI-powered cargo invoice processing platform that automates extraction, validation, interpretation, and posting of freight invoice data directly into CargoWise via e-Adapter integration — cutting out hours of manual data entry for freight forwarders. At its core is a fine-tuned Qwen Vision Language Model trained specifically on cargo invoices, letting it understand both visual layout and dense logistics terminology rather than relying on OCR text extraction alone. The result holds up on messy, inconsistently formatted invoices that traditional OCR pipelines routinely misread.
